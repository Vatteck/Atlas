# Browse 2.0 polish (2026-06-05)

**Backlog item:** "Browse 2.0 (Arch polish) — richer category cards (icon + count + short
description), breadcrumbs, persist last-opened category, better category-page skeletons."

## Why
Browse is functional (categories + AUR discovery + Flatpak-in-bucket + suggested row) but the landing
is bare and the category pages flash a plain spinner. This is frontend-heavy, high-perceived-polish.

## Scope decisions
- **No count on category cards.** Counts were deliberately dropped (the repo-only count understates a
  bucket that also lists Flathub apps — see the "misleading category chip counts" fix). The richer
  card adds an **icon + short description** instead. (AUR buckets keep their truthful count.)
- Persist last-opened category as a **resume affordance**, not auto-navigation (auto-jumping away
  from the landing would be surprising).

## Changes
### Backend (small)
- `CATEGORY_BUCKETS`: append a 6th element — a short **description** per bucket (existing index-based
  unpacking in `get_category_packages` is unaffected; `bucket[3]`/`bucket[4]` stay valid).
- `get_categories`: include `description` in each returned bucket.

### Frontend
- **Richer category cards** — pure `buildCategoryCardHTML(c)` (icon + label + description; no count).
- **Breadcrumbs** — `browseCategoryHeader` renders `Browse / <Category>` (the "Browse" crumb is a
  button back to the landing) instead of the bare "← Categories" button.
- **Persist last-opened category** — `setLastBrowseCategory`/`getLastBrowseCategory` (localStorage
  `atlas_last_browse_cat` = `{key,label,api}`), written when a category opens. The landing shows a
  pure `buildResumeBrowseHTML(last)` "Jump back to <label>" chip at the top (only when one is stored
  and it isn't the obvious empty case); clicking it reopens that category/bucket.
- **Better category-page skeletons** — `renderCategoryPackages` shows the breadcrumb + the existing
  `getSkeletonGridHTML()` while loading, instead of a plain centered spinner.

### Tests
- `main_js_contracts` — `buildCategoryCardHTML` (icon/label/description, escaping, no count),
  `buildResumeBrowseHTML` (chip when present, '' when null), breadcrumb markup.
- No backend test beyond the existing `BrowseCategoryTest`/`get_categories` (description is additive);
  add a `description` assertion to the categories test.

## Non-goals
- No Arch/Flatpak/All tabs within a bucket (the `collapseByName` merge already unifies them; tabs are
  a separate possible follow-up).
- No per-bucket network counts.
