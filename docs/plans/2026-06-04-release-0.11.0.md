# 2026-06-04 — Release prep: 0.11.0 (first cohesive Atlas release)

## Why 0.11.0

`__version__` has read `0.10.7` since the initial Atlas commit (2026-05-28) — it was
inherited from bauh and never bumped. Everything that makes Atlas *Atlas* (the bauh→Atlas
rebrand, the Qt5→pywebview UI, the Rust removal → pure-Python, the Arch focus, and every
shipped theme) landed on top of it. So this is effectively the first real Atlas release. A
**minor** bump (0.10.7 → 0.11.0) marks the accumulated feature set honestly; `1.0.0` would
overclaim while the codebase is still maturing and carries many "needs a GUI eyeball" items.

## Steps

1. **Version bump** — `atlas/__init__.py` `__version__ = '0.11.0'` (single source of truth;
   `pyproject.toml`, `setup.py`, the About dialog, `--version`, and the PKGBUILD `pkgver()`
   all read it).
2. **README** — `v0.10.7` → `v0.11.0` in the status line.
3. **PKGBUILD + .SRCINFO** — bump the `pkgver=` placeholder to `0.11.0` for hygiene. (For a
   `-git` package the real `pkgver` is auto-computed at build from `__version__` + git
   rev-count + short hash, so this is cosmetic, but it keeps the tracked files honest.)
4. **CHANGELOG.md** — new file. A curated `0.11.0` section grouped by theme (not a 190-commit
   dump), sourced from `docs/STATUS.md`'s Done log.
5. **Verify** — `python -m build --wheel --no-isolation` produces a `py3-none-any` wheel;
   `python -m pytest` stays green.
6. **Tag** — annotated `v0.11.0` locally. Pushing the tag is left to the user (outward-facing).
7. **STATUS.md** — record the release.

## Out of scope here (user-gated, outward-facing)

- **AUR publish.** `linux_dist/arch/publish-aur.sh` clones `atlas-pm-git`, copies the PKGBUILD,
  regenerates `.SRCINFO`, and **pushes to the AUR** (needs the AUR SSH key). This is outward-
  facing and irreversible-ish, so it is **not** run as part of this prep — surfaced for the user
  to run (`./linux_dist/arch/publish-aur.sh` or `--dry-run` first). Since it's a `-git` package,
  re-publishing only matters when PKGBUILD/.SRCINFO content actually changes.
